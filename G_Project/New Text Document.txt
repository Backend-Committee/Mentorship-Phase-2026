📄 Software Requirements Specification (SRS)
Adhkar Backend Web Application
1. Introduction
1.1 Purpose

This project is a backend web application that helps users track Morning, Evening, and Free Adhkar (Islamic remembrances). The system includes a gamification feature based on points and motivational rewards represented by a “Ketkot 🐥” character when users achieve specific milestones.

1.2 Scope

The system provides:

User registration and authentication
Display of Adhkar based on categories
User progress tracking
Points system for each completed Adhkar
Rewards and levels system
Daily notification system for Adhkar
1.3 Users
Regular User
Admin (optional for content management)
2. Functional Requirements
2.1 Authentication
Create new account
Login and logout
Secure password storage (hashed passwords)
2.2 Adhkar Management
Predefined Adhkar in the system
Categories:
Morning Adhkar
Evening Adhkar
Free Adhkar
2.3 Progress Tracking
Users can mark Adhkar as completed
Each completion is recorded in the system
Points are added for each completed Adhkar
2.4 Gamification System
Users earn points for each completed Adhkar
Rewards are unlocked at milestones (10 - 50 - 100 points)
A “Ketkot 🐥” character appears upon achievement
Levels and badges system
2.5 Dashboard
Display total points
Show number of completed Adhkar
Show current level
Show unlocked rewards
2.6 Notification System
Notifications for Morning and Evening Adhkar
Enable/disable notifications
Set custom notification time
Daily recurring notifications
