# ERD-School-System

## Overview

### The design represents a school system where:
- The school has multiple levels.
- Each level has many subjects and may have multiple classes.
- For each subject, there may be many teachers.
- Teachers could teach different classes or just one class, and many subjects.
- A student can belong to only one class per year but can take subjects multiple times.
